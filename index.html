Come funziona.

Nessun server, nessun abbonamento. Ogni strumento è un solo file che il browser apre e fa girare sul tuo computer.

01 — PRIVATOI testi restano tuoi.

Niente viene caricato online. Il lavoro si salva nel browser e, con "Salva", in un file sul tuo computer.

02 — LEGGEROSi apre e basta.

Nessuna installazione, nessun account. Funziona in Chrome, Edge e Firefox, anche senza connessione una volta aperto.

03 — STAMPABILEPronto per chi legge.

PDF con font incorporati, formati e margini standard: l'editore o il produttore lo apre subito, senza sorprese.
